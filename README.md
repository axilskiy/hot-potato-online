# 🥔 Hot Potato Online

Многопользовательская игра «Горячая картошка» в реальном времени. Передавай картошку другим игрокам — тот, кто держит её когда таймер истекает, выбывает. Последний выживший побеждает.

---

## Стек технологий

| Часть | Технологии |
|-------|-----------|
| **Сервер** | Node.js · Express · Socket.IO · TypeScript |
| **Клиент** | Vue 3 · Pinia · Vue Router · Socket.IO client · Vite · TypeScript |

## Быстрый старт

### 1. Сервер

```bash
cd server
npm install
npm run dev
# → http://localhost:3000
```

### 2. Клиент (в отдельном терминале)

```bash
cd client
npm install
npm run dev
# → http://localhost:5173
```

Открой `http://localhost:5173` в браузере. Vite автоматически проксирует Socket.IO запросы на сервер.

## Правила игры

1. Введи никнейм и выбери аватар на главной странице
2. Создай комнату (ты станешь хостом) или войди по 6-значному коду
3. Минимум **3 игрока** для старта
4. Хост настраивает параметры комнаты и нажимает «Начать игру»
5. Один случайный игрок получает картошку — подойди к другому игроку, чтобы передать
6. Таймер тикает согласно настройке длительности раунда (10 / 15 / 20 / 30 секунд)
7. Когда таймер истекает — игрок с картошкой **выбывает**
8. После каждого выбывания игра продолжается, пока не останется один победитель
9. По арене появляются **бонусы (Power-Ups)** — подбери их, наступив на них!

### Очки

| Место | Очки |
|-------|------|
| 1-е (победитель) | 3 |
| 2-е | 2 |
| 3-е | 1 |

## Power-Ups (бонусы)

На арене случайно появляются бонусы каждые 8–15 секунд. Одновременно на карте не более 3 бонусов.

| Бонус | Иконка | Эффект | Длительность |
|-------|--------|--------|-------------|
| **Speed Boost** | ⚡ | +50% скорость передвижения | 5 секунд |
| **Shield** | 🛡 | Картошка не может быть передана этому игроку | 5 секунд |
| **Freeze** | ❄️ | Следующий игрок, которого ты коснёшься, будет заморожен на 2 секунды | До использования |

### Правила бонусов

- **Подбор**: наступи на бонус (подойди вплотную) — он исчезает и эффект применяется
- **Стакинг**: повторный подбор того же типа продлевает время действия, не суммирует
- **Щит**: защищает от передачи картошки, но не от взрыва (таймер продолжает тикать)
- **Заморозка (носитель)**: после подбора ❄️ у тебя появляется заряд — касаешься врага → он замораживается на 2 сек, заряд сгорает
- **Заморозка (жертва)**: замороженный игрок не может двигаться

### Визуальные индикаторы

| Эффект | Визуал |
|--------|--------|
| Speed | Синее свечение вокруг игрока |
| Shield | Фиолетовое кольцо вокруг игрока |
| Freeze (носитель) | ❄️ иконка над игроком |
| Freeze (заморожен) | 🧊 иконка + голубой оверлей на игроке |

Активные эффекты отображаются в HUD (правый верхний угол арены).

  id: string
  type: PowerUpType

  y: number

  // ... существующие поля ...

  freezeUntil?: number   // timestamp окончания заморозки (жертва)
  hasFreezeCharge?: boolean  // есть заряд заморозки (носитель)

// Новые поля в GameState:

  // ... существующие поля ...

}

// Новые поля в Room (только сервер):
interface Room {
  // ... существующие поля ...

}

## Socket.IO события

### Клиент → Сервер

| Событие | Данные | Описание |
|---------|--------|----------|
| `create_room` | `{ nickname, avatar }` | Создать комнату |
| `join_room` | `{ roomId, nickname, avatar }` | Войти в комнату |
| `start_game` | `{ roomId }` | Начать игру (хост) |
| `pass_potato` | `{ roomId, toId }` | Передать картошку |
| `player_move` | `{ x, y }` | Обновить позицию |
| `restart_game` | `{ roomId }` | Новая игра (хост) |
| `return_to_lobby` | `{ roomId }` | Вернуться в лобби (хост) |
| `update_settings` | `{ roomId, settings }` | Изменить настройки (хост) |
| **`collect_powerup`** | `{ powerUpId }` | **Подобрать бонус** |
| **`use_freeze`** | `{ targetId }` | **Применить заморозку к игроку** |

### Сервер → Клиент

| Событие | Данные | Описание |
|---------|--------|----------|
| `room_joined` | `{ roomId, player, gameState }` | Подтверждение входа |

## Тестирование

### На ПК

1. Запусти сервер и клиент
2. Открой 3+ вкладки по адресу `http://localhost:5173`
3. Создай комнату в одной вкладке, войди в остальные по коду
4. Запусти игру

### Тестирование Power-Ups

| Бонус | Как проверить |
|-------|---------------|
| ⚡ Speed | Подбери — персонаж должен начать двигаться быстрее (синее свечение, HUD показывает «⚡ Скорость») |
| 🛡 Shield | Подбери — другой игрок с картошкой не сможет передать её тебе (фиолетовое кольцо, 5 сек) |
| ❄️ Freeze | Подбери → иконка ❄️ над головой → коснись другого игрока → он замирает на 2 сек (🧊 оверлей) |

## Особенности реализации

- **Сервер — единственный источник правды**: спавн, подбор, удаление и длительность power-ups полностью управляются сервером
- **Оптимистичная коллизия**: клиент отправляет `collect_powerup` при обнаружении пересечения, сервер валидирует — исключены дубли через `pendingCollects`
- **Freeze-заряд**: заморозка — двухэтапный эффект (подбор → накопление заряда → применение к жертве при касании)
- **Щит и передача**: `passPotato()` на сервере проверяет `shieldUntil > Date.now()` и блокирует передачу
- **Таймеры заморозки на сервере**: `PLAYER_MOVE` игнорируется, пока `freezeUntil > Date.now()`; клиент дублирует проверку для мгновенного отклика
- **Без базы данных** — все данные в памяти (`Map`), сбрасываются при перезапуске сервера
